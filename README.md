# Архитектура проекта

Основная логика программы построена вокруг двух ключевых классов:


## `VirtualFileSystem`

Класс `VirtualFileSystem` отвечает за управление виртуальной файловой системой.

Основным элементом является:

```python
self.root
```

который представляет корневую директорию `/`.

Класс предоставляет механизм:

1. создания пустой VFS;
2. загрузки физической директории в память;
3. рекурсивного обхода директорий;
4. поиска узла по пути.

Загрузка физической директории выполняется рекурсивно.

Например, физическая структура:

```text
my_vfs/
├── file.txt
├── folder/
│   ├── test.txt
│   └── data.txt
└── another/
    └── example.txt
```

после загрузки превращается в аналогичное дерево объектов в оперативной памяти.

---

## `ShellEmulator`

`ShellEmulator` является основным классом приложения.

Он отвечает за:

* создание графического окна;
* отображение терминала;
* обработку пользовательского ввода;
* разбор команд;
* выполнение команд;
* работу с текущим каталогом;
* выполнение стартового скрипта;
* вывод сообщений и ошибок.

Команды передаются в единый обработчик:

```python
process_command()
```

После разбора команды вызывается соответствующий метод.

```text
ls       → command_ls()
cd       → command_cd()
find     → command_find()
cp       → command_cp()
mv       → command_mv()
```

# Виртуальная файловая система

Одной из основных особенностей проекта является использование виртуальной файловой системы.


---

## Загрузка VFS

Если при запуске указать:

```text
--vfs <путь>
```

программа считывает содержимое указанной физической директории.

Например:

```bash
python main.py --vfs ./vfs --script ./scripts/startup.txt
```

Если `./vfs` содержит:

```text
vfs/
├── file1.txt
├── file2.txt
└── folder/
    └── test.txt
```

то после запуска виртуальная файловая система будет иметь такую же структуру.

# Параметры запуска

Программа поддерживает параметры командной строки.

## `--vfs`

Указывает физическую директорию, содержимое которой используется как начальное состояние виртуальной файловой системы.

Пример:

```bash
python main.py --vfs ./vfs
```

После запуска:

```text
VFS: C:\project\vfs
```

---

## `--script`

Указывает файл со стартовым скриптом.

Пример:

```bash
python main.py --script ./scripts/startup.txt
```

Команды из файла будут автоматически выполнены после запуска приложения.

---

## Использование обоих параметров

Наиболее полный вариант:

```bash
python main.py --vfs ./vfs --script ./scripts/startup.txt
```

В таком случае:

1. создаётся VFS;
2. в неё загружается содержимое `./vfs`;
3. запускается графический интерфейс;
4. выполняются команды из `startup.txt`.

# Работа со стартовым скриптом

Стартовый скрипт представляет собой обычный текстовый файл.

Каждая строка содержит отдельную команду.

Например:

```text
ls
cd folder
ls
cd ..
echo Hello
```

При запуске программа последовательно выполняет команды.

Перед выполнением команды она выводит её в интерфейс:

```text
$ ls
```

---

## Остановка при ошибке

Если команда завершилась с ошибкой, выполнение стартового скрипта прекращается.

Например:

```text
ls
cd folder
cd nonexistent
echo Hello
```

Если `nonexistent` не существует, последняя команда:

```text
echo Hello
```

выполнена не будет.

Это позволяет использовать стартовые скрипты для автоматизированного тестирования команд.

# Поддерживаемые команды

## `ls`

Выводит содержимое текущей директории.

Использование:

```bash
ls
```

Пример:

```text
$ ls
documents/ file.txt games/
```

Директории обозначаются символом:

```text
/
```

в конце имени.

Также можно указать путь:

```bash
ls documents
```

или:

```bash
ls /documents
```

---

# `cd`

Изменяет текущую директорию.

Использование:

```bash
cd <путь>
```

Пример:

```bash
cd documents
```

После этого текущая директория изменится на:

```text
/documents
```

Для перехода на уровень выше:

```bash
cd ..
```

Для перехода в корневую директорию:

```bash
cd /
```

---

## Пример

Начальное состояние:

```text
/
├── documents/
└── file.txt
```

Выполняем:

```text
$ cd documents
```

Текущий путь:

```text
/documents
```

Затем:

```text
$ cd ..
```

Возвращаемся:

```text
/
```

---

# `whoami`

Выводит имя пользователя, под которым запущена программа.

Использование:

```bash
whoami
```

Пример:

```text
$ whoami
User
```

Команда не принимает аргументы.

---

# `find`

Выполняет рекурсивный поиск объекта в виртуальной файловой системе.

Команда работает с содержимым VFS, а не напрямую с физической файловой системой.

Базовый вариант:

```bash
find
```

Поиск по имени:

```bash
find file.txt
```

В зависимости от реализованного синтаксиса можно указать путь поиска и имя объекта.

Например:

```bash
find /documents report.txt
```

Поиск осуществляется рекурсивно.

Если объект найден, программа выводит его путь.

---

## Пример

VFS:

```text
/
├── documents/
│   ├── report.txt
│   └── notes.txt
└── backup/
    └── report.txt
```

Команда:

```bash
find report.txt
```

может вернуть:

```text
/documents/report.txt
/backup/report.txt
```

---

# `echo`

Выводит переданный текст.

Использование:

```bash
echo <текст>
```

Пример:

```bash
echo Hello World
```

Результат:

```text
Hello World
```

Можно использовать команду для проверки работы парсера аргументов и стартовых скриптов.

---

# `cp`

Копирует объект внутри виртуальной файловой системы.

Поддерживаются файлы и директории.

Общий синтаксис:

```bash
cp <источник> <назначение>
```

---

## Копирование файла

Например:

```bash
cp file.txt copy.txt
```

Было:

```text
/
└── file.txt
```

Станет:

```text
/
├── file.txt
└── copy.txt
```

---

## Копирование файла в директорию

```bash
cp file.txt documents/
```

Результат:

```text
/
├── file.txt
└── documents/
    └── file.txt
```

---

## Копирование директории

```bash
cp documents backup
```

Создаётся копия всей директории:

```text
/
├── documents/
│   ├── report.txt
│   └── notes.txt
└── backup/
    ├── report.txt
    └── notes.txt
```

Для копирования используется глубокое копирование дерева VFS, поэтому исходная и скопированная директории являются независимыми объектами.

---

# `mv`

Перемещает или переименовывает объект внутри виртуальной файловой системы.

Общий синтаксис:

```bash
mv <источник> <назначение>
```

---

## Переименование

```bash
mv file.txt new_name.txt
```

Было:

```text
file.txt
```

Станет:

```text
new_name.txt
```

---

## Перемещение файла

```bash
mv file.txt documents/
```

Было:

```text
/
├── file.txt
└── documents/
```

Станет:

```text
/
└── documents/
    └── file.txt
```

---

## Перемещение директории

```bash
mv documents backup
```

Директория будет перемещена в указанное место.


---

# `vfs-init`

Переинициализирует виртуальную файловую систему.

Использование:

```bash
vfs-init
```

Команда не принимает аргументов.

После выполнения:

* текущая VFS очищается;
* создаётся новая пустая VFS;
* текущий путь сбрасывается в корень;
* при использовании физической директории её содержимое также очищается согласно логике инициализации проекта.

После выполнения:

```bash
ls
```

покажет пустую директорию.

> `vfs-init` является специальной служебной командой проекта. В отличие от обычных операций VFS, она может изменять физическое представление VFS.

---

# `exit`

Завершает работу приложения.

Использование:

```bash
exit
```

Команда не принимает аргументов.

При выполнении закрывается графическое окно эмулятора.

---

# Обработка ошибок

Программа проверяет корректность команд и их аргументов.

Например, если пользователь введёт неизвестную команду:

```text
hello
```

будет выведено сообщение:

```text
Ошибка: неизвестная команда 'hello'
```

---

## Несуществующий путь

Например:

```bash
cd nonexistent
```

Если такой директории нет, программа сообщает об ошибке.

---

## Неверное количество аргументов

Например:

```bash
mv file.txt
```

Команда требует два аргумента:

```text
mv <источник> <назначение>
```

Поэтому программа завершает обработку команды с ошибкой.

---

## Попытка использовать файл как директорию

Например:

```bash
cd file.txt
```

если `file.txt` является файлом, а не директорией.

Такая операция запрещена.
